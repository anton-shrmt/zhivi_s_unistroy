# Живи с Унистрой — лендинг

Статический сайт: один `index.html` + шрифты + изображения. Сборка не требуется —
папка выкладывается на веб-сервер как есть.

## Что нужно сделать при выкладке

1. **amoCRM.** В `index.html` найдите `AMOCRM_CONFIG` (блок `<script>` внизу файла):
   - `endpoint` — URL прокси/API для приёма заявок (POST, JSON);
   - `dryRun` — поставить `false` после подключения endpoint;
   - `pipelineId`, `statusId`, `responsibleUserId` — по необходимости.
   Пока `dryRun: true` — форма показывает успех, но заявка никуда не отправляется
   (payload пишется в консоль браузера). Структура payload — функция `buildAmoLeadPayload`.

2. **og:image.** В `<head>` замените относительный путь на абсолютный URL с доменом:
   `<meta property="og:image" content="https://<домен>/img/hero.jpg">`.

3. **Ссылки-заглушки (`href="#"`)** — проставить реальные адреса, когда будут:
   - «Написать в мессенджер» (в форме заявки);
   - Telegram / ВКонтакте / WhatsApp в футере.

## Примечания

- Коэффициенты калькулятора — в объекте `CONFIG` там же в `<script>`.
- Шрифты: браузер загружает только используемые начертания (Regular/Medium/Bold),
  остальные файлы лежат про запас.
- Кодировка UTF-8, отдавать `index.html` с `Content-Type: text/html; charset=utf-8`.
