# Общее меню Унистрой

Эталон: https://unistroy.ru/, Казань, 05.10.2026. Это автономная статическая копия
интерфейса для передачи разработчикам. Подключение к приложению головного сайта,
CRM выполняется на этапе интеграции.

## Файлы

- `reference.css`: правила оформления оригинала, ограниченные `#sharedHeader`.
  Единицы `rem` преобразованы в локальную переменную `--ref-unit`, чтобы размеры
  шапки соответствовали оригиналу и не меняли типографику лендинга.
- `header.css`: интеграция, фокус, обработка касаний и доступность элементов.
- `templates.js`: исходная структура desktop, mobile, tablet и диалогов.
- `header.js`: переключение разделов, тем, карточек, управление фокусом и формой.
- `catalog.json`: единый список разделов и проектов для всех вариантов.

Статическая шапка в `index.html` находится между маркерами `SHARED_HEADER_START`
и `SHARED_HEADER_END`. После загрузки её активирует `header.js`. Порядок подключения:
`reference.css`, `header.css`, затем `templates.js`, `header.js`. Стили, обработчики
и форма заявки аренды остаются отдельными.

## Данные и внешние зависимости

В шапке 14 проектов, 4 категории недвижимости, по 6 пунктов парковок и кладовых.
По решению заказчика количество доступных квартир, машино-мест и кладовых,
а также цены «от» удалены из статического меню. Это намеренное отличие
от головного сайта, чтобы не показывать устаревшие остатки и цены. Генератор
исключает эти данные из новых снимков, поэтому они не вернутся при повторной
сборке. У карточек убраны пустые строки и подписи, повторяющие название проекта.
Автообновление цен и остатков для этой версии меню не требуется.

Для обновления снимка меняют `catalog.json` и запускают
`python3 release_header/qa/menu/build_header.py` из корня website (нужен `lxml`).
Генератор обновляет шаблоны, CSS и статическую шапку. Добавление/удаление проектов
или изменение структуры требует обновления исходных DOM-снимков в `qa/menu/`.
Генератор использует локальные сохранённые данные, сеть ему не нужна.

Шрифты локальные и совпадают с оригинальными файлами. Изображения карточек
используют исходные URL CDN `unistroy.ru`. При переносе на другой сервер проверить
CSP для изображений этого домена и доступность CDN.

Телефон во всех вариантах меню постоянный: **+7 (960) 069-30-30**,
ссылка `tel:+79600693030`. По решению заказчика номер не подменяется.
Коллтрекинг и динамическую замену номера на этой странице не подключать.
Генератор закрепляет этот номер в статической шапке, всех шаблонах и доступных
подписях кнопки звонка, независимо от номера в новых снимках головного сайта.

Города открывают соответствующие региональные разделы головного сайта. Клик по
Казани закрывает выбор. Избранное, проекты, социальные сети и остальные ссылки
ведут на исходные страницы. Личный список избранного головного сайта в локальном
лендинге не синхронизируется.

## Обратный звонок

Это отдельная форма продаж из общей шапки. Она не использует `AMOCRM_CONFIG`
формы аренды. Поля имени, телефона и согласия на обработку данных обязательны;
согласие на рекламу необязательно. Все галочки изначально сняты.

После успешной проверки полей компонент посылает всплывающее DOM-событие
`unistroy:callback-ready` с `detail`:

```js
{
  name, phone, city: 'kzn', taxi,
  consent: { personalData: true, marketing, capturedAt },
  source: 'shared-header'
}
```

Разработчики могут обработать это событие своим приложением либо перед загрузкой
`header.js` задать `window.UNISTROY_HEADER_CONFIG = { callbackEndpoint: '/api/…' }`.
Компонент отправит JSON POST и покажет подтверждение только после HTTP 2xx.
Не подключайте оба способа одновременно, чтобы не создать дубли.
Endpoint по умолчанию отсутствует: отправки и ложного подтверждения успеха нет.

Сервер должен проверять входные данные, сохранять заявку и доказательства согласий,
применять ограничения частоты и необходимую защиту формы. Юридические ссылки в
этом диалоге сохранены из оригинала. До включения отправки согласовать с юристами
оператора, адреса и версии документов, серверный журнал и маршрутизацию заявки.
Не считать время браузера серверным доказательством согласия. Секреты CRM в
статические файлы не помещать. Текст документов лендинга не изменялся.

## Проверка и отличия поведения

Матрица, история обнаруженных/исправленных ошибок, проверка адресов и парные
снимки находятся в `../qa/menu/`. Точка входа: `report.html`.
Матрица из 118 сравнений относится к версии до согласованного удаления счётчиков
и цен. Проверки этих изменений сохранены в `inventory-removal.json`
и `price-removal.json`.
В копии восстановлены работающие кнопки «Назад»/закрытия мобильного меню,
добавлены Enter/Space/Escape, перемещение по категориям стрелками/Home/End,
возврат фокуса, управление карточками клавиатурой и учёт reduced motion.
Эти исправления доступности могут отличаться от ошибок поведения исходного сайта.
Промокарточки переключаются точками и свайпом; точные промежуточные кадры анимации
и автопрокрутка оригинального Swiper отдельно не сертифицированы.

На повторной проверке 06.10.2026 все семь ссылок способов покупки открылись
в браузере с HTTP 200. Предыдущая ошибка HTTP 500 больше не воспроизводится.
В мобильной промокарточке оригинала также обнаружен
`https://google.com/`; исходный адрес сохранён для точного соответствия и отмечен
в отчёте. Исправления этих адресов следует вносить согласованно с головным сайтом.

Актуальный итоговый QA: `../qa/final-2026-10-06/report.html`. В этой версии
закреплён телефон аренды, восстановлен фокус настольных кнопок после открытия
меню, чекбоксы доступны с клавиатуры. Встроенная отправка блокирует повторы,
требует полный номер +7 из 11 цифр и нормализует ввод с начальной 8.
